# Chicago Crime Dashboard

An interactive **Streamlit** web application for exploring and analyzing crime data in Chicago.  
The project visualizes crime incidents on a map and provides filters to better understand crime trends by location, type, and time.

---

## 🚀 Features
- Interactive map of Chicago crime incidents  
- Filter by crime type, date, and location  
- Charts and statistics for crime trends  
- Easy-to-use Streamlit interface
